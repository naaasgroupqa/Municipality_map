# Municipality Map — Qatar Road Evolution

Interactive exhibition-style prototype showing the evolution of Qatar's road network from 1950 to 2026.

## Features
- Adjustable year slider from 1950–2026
- Play / pause historical animation
- Decade milestone navigation
- Animated road growth layers
- Bilingual English / Arabic phase labels
- Exhibition-friendly full-screen responsive layout
- Optional labels and map grid

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy on GitHub Pages
For production, deploy the Vite `dist` output through GitHub Actions / Pages, or connect this repository to Vercel / Netlify.

## Data note
The current road chronology is an **illustrative reconstruction for concept demonstration only**. Before official Ministry use, replace the sample road paths and milestone narrative with verified historical GIS road layers / archival road datasets.

## Branding note
The current interface uses a Ministry-style bilingual identity treatment. For official delivery, replace the temporary crest treatment with the Ministry of Municipality's approved master logo asset supplied by the client / Ministry brand guidelines.
